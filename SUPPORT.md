# Support

## GitHub Issues

Use [GitHub Issues](https://github.com/taras-polishchuk/operatoros-platform/issues) for reproducible bug reports and scoped feature requests. Include version, Node/pnpm versions, profile, relevant logs, and a minimal reproduction. Remove secret material before posting. A general public discussion channel is not currently configured.

## Security

Do not disclose vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md) and use the linked GitHub private vulnerability-report form with impact, reproduction steps, and a safe contact channel.

## Response expectations

We aim to acknowledge security reports within 48 hours and triage them within 7 days. Community responses are best-effort; provide enough detail for maintainers to reproduce the issue. Release and security timelines are documented in the security policy.
