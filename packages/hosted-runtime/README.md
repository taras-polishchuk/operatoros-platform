# `@operatoros-platform/hosted-runtime`

> **Hosted Runtime · multi-tenant deployment shape · v1.0.0**

## What

Provides the operator-hosted profile shape, including tenant registration and request attribution/digest fields for audit while retaining the shared platform contracts.

## Quick start

```ts
import { createHostedRuntime } from '@operatoros-platform/hosted-runtime';
```

## API surface
