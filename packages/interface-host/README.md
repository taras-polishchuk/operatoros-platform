# `@operatoros-platform/interface-host`

> **Interface Host · one command/query boundary · v1.0.0**

## What

Attributes requests and dispatches the shared interface contract for local CLI, HTTP/API, SDK, and optional UI surfaces. It keeps transport behavior from becoming a second authority.

## Quick start

```ts
import { createInterfaceHost, INTERFACE_OPERATIONS } from '@operatoros-platform/interface-host';
```

## API surface

Generate the API reference locally with `pnpm docs:build`.
