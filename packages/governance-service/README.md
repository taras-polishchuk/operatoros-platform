# `@operatoros-platform/governance-service`

> **Governance Service · explicit operator authority · v1.0.0**

## What

Manages Operator Profiles, explicit Capability Grants, Configuration Revisions, and the Effective Configuration projection used to authorize work.

## Quick start

```ts
import { createGovernanceService } from '@operatoros-platform/governance-service';
```
