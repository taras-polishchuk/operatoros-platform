# `@operatoros-platform/contracts`

> **Contracts · canonical vocabulary · v1.0.0**

## What

Shared schemas and contract vocabulary for the Platform's 14 entities, five envelopes, and extension manifest. This package keeps boundaries explicit and strict.

## Quick start

```ts
import { MissionRecordSchema, RunSchema } from '@operatoros-platform/contracts';
```

## API surface

Generate the API reference locally with `pnpm docs:build`.
