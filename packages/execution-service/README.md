# `@operatoros-platform/execution-service`

> **Execution Service · recoverable Mission Runs · v1.0.0**

## What

Executes Mission Execution Specifications as Runs, owns the eight-state `RUN_STATES` machine, coordinates adapters, and records checkpoints and Mission Record evidence with optimistic concurrency.

## Quick start

```ts
import { createExecutionService } from '@operatoros-platform/execution-service';
```
