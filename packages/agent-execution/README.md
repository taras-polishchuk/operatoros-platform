# `@operatoros-platform/agent-execution`

> **Agent Execution · capability-matched invocation · v1.0.0**

## What

Registers agents, matches requested capabilities against operator grants, routes invocations, and persists agent results through the platform's evidence boundary.

## Quick start

```ts
import { createAgentExecutionService } from '@operatoros-platform/agent-execution';
```
