# `@operatoros-platform/workspace-service`

> **Workspace Service · operator-scoped durable records · v1.0.0**

## What

Coordinates validated Workspace and Artifact mutations, snapshots, configuration, grants, and Workspace-scoped projections while delegating evidence acknowledgement to Evidence Service.

## Quick start

```ts
import { createWorkspaceService } from '@operatoros-platform/workspace-service';
```
