# `@operatoros-platform/secrets-service`

> **Secrets Service · preview-only security boundary · v1.0.0**

## What

Manages Secret References and resolution boundaries. Raw secret values are not persisted; operator-visible material is limited to four-character previews.

## Quick start

```ts
import { createSecretsService } from '@operatoros-platform/secrets-service';
```

## API surface

Generate the API reference locally with `pnpm docs:build`.
