# `@operatoros-platform/extension-runtime`

> **Extension Runtime · staged and grant-scoped lifecycle · v1.0.0**

## What

Runs extensions through stage, validate, activate, suspend, retire, and uninstall lifecycle boundaries, denying undeclared capability requests.

## Quick start

```ts
import { createExtensionRuntime } from '@operatoros-platform/extension-runtime';
```
