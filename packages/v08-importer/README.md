# `@operatoros-platform/v08-importer`

> **v0.8 Importer · non-destructive migration · v1.0.0**

## What

Reads OperatorOS v0.8.x data without modifying the v0.8 source and produces OperatorOS Platform artifacts for migration and review.

## Quick start

```ts
import { createV08Importer } from '@operatoros-platform/v08-importer';
```

## API surface

Generate the API reference locally with `pnpm docs:build`.
