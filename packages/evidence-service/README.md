# `@operatoros-platform/evidence-service`

> **Evidence Service · append-only ledger · v1.0.0**

## What

Authoritative evidence persistence: Mission Records, immutable Event Records, mutation envelopes, integrity verification, sealing, and rebuildable projections. It never invents missing evidence.

## Quick start

```ts
import { createEvidenceService } from '@operatoros-platform/evidence-service';
```
