# `@operatoros-platform/recovery-service`

> **Recovery Service · fencing-token recovery · v1.0.0**

## What

Provides recovery leases, checkpoint and snapshot restoration, fencing-token preemption, and deterministic dual-contender resolution so zombie processes cannot advance state.

## Quick start

```ts
import { createRecoveryService } from '@operatoros-platform/recovery-service';
```
